# QuickBite 🍔  
A modern and responsive food delivery frontend website built using HTML, CSS, and JavaScript.

QuickBite is a visually engaging food ordering web interface designed to provide users with a smooth and interactive browsing experience. The project includes dynamic food sections, animated UI components, responsive layouts, and an interactive shopping cart system.

---

## 🚀 Features

- Fully Responsive Design for Mobile, Tablet, and Desktop
- Interactive Add to Cart Functionality
- Dynamic Cart Total Calculation using JavaScript
- Sticky Navigation Bar
- Smooth Horizontal Food Sliders
- Animated Offer Cards Section
- Video Banner Section
- Modern UI/UX Design
- Food Categories:
  - Burgers
  - Fries
  - Wraps
  - Soups & Veggie Specials
- Contact Section
- Hover Effects & Animations

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
